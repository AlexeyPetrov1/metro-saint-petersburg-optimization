# Диагностика шаблонной замены YandexGPT

Проверен один сохранённый пакет `balanced/explanations/facts_03600.json`, для которого
рабочий процесс ранее записал `invalid_response`. Выполнен один вызов существующего
провайдера, фактически один API-запрос. Повторных запросов не было.

Получен точный код `ExplanationError`: **`invalid_evidence_ids`**.
В секции `rationale` модель вернула три ID фактов с одним повтором.
Это нарушает `uniqueItems` в JSON Schema и проверку уникальности в валидаторе.

Поля ответа, все шесть секций, `run_id`, `decision_id` и `context_hash` совпали
с ожидаемыми. ID были строковыми, присутствовали в пакете и соответствовали
допустимым типам фактов своих секций. Шаблонная замена в этом случае сработала
из-за повторного ID.

Ответ занял 6,813 секунды: 26 600 входных и 158 выходных токенов.
Результат одного запроса не определяет причины всех остальных шаблонных замен.

`result.json` содержит проверки структуры и контрольные суммы.
Сгенерированный свободный текст, ключи и HTTP-заголовки не сохранялись.
Неизвестные строковые ID заменяются SHA256 в диагностике.
Оба теста диагностики прошли. Исходники, пакет фактов и сохранённое объяснение
сохранили прежние SHA256; рабочие процессы продолжаются.

Для следующей версии можно отдельно проверить удаление повторов известных ID
до основной валидации. Такое изменение требует тестов; неизвестные ID,
неверные типы фактов, изменения контекста и действия должны по-прежнему отклоняться.
В текущую работающую версию это изменение не внесено.
